# 🔐 Password Strength Analyzer

A simple and effective **Password Strength Analyzer** built using Python that checks how secure a password is based on different criteria.

---

## 📌 Overview

This project helps users understand whether their password is **Weak, Medium, or Strong** by analyzing common security factors.  

It is a beginner-friendly cybersecurity project that demonstrates how password validation works.

---

## 🚀 Features

- ✔ Checks password length  
- ✔ Detects uppercase and lowercase letters  
- ✔ Verifies numbers  
- ✔ Identifies special characters  
- ✔ Provides strength rating (Weak / Medium / Strong)  

---

## 🛠️ Tech Stack

- Python 3  
- Basic string operations  
- Conditional statements
